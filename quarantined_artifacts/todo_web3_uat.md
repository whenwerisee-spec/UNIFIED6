# Web3 Wallet & Portfolio Balancer UAT Matrix

- [x] Phase 1: Inventory and map the Smart Portfolio Balancer, Web3 wallet, supported assets, networks, signers, gas sources, and transaction routes
- [x] Phase 2: Run read-only live checks for wallet ownership, addresses, balances, token metadata, network detection, gas estimation, quote calculation, and provider connectivity
- [x] Phase 3: Test wallet signing and transaction construction on real networks, pausing before any irreversible broadcast until the exact asset, amount, destination, network, and consequence are confirmed
- [x] Phase 4: After explicit confirmation, execute only the bounded live transaction, verify provider and explorer evidence, reconcile the app ledger, and test alert and failure recovery behavior
- [x] Phase 5: Deliver the evidence-based wallet and portfolio report with pass, fail, blocked, and unverified outcomes and preserve all changes locally for approval
